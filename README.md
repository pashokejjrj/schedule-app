# Расписание занятий (Модульная версия)

Модульное веб-приложение для составления и просмотра расписания учебных занятий, декомпозированное из монолитного однофайлового приложения `schedule-app.html` на стек **Vite + TypeScript + CSS Modules + Vitest**.

## 📁 Структура проекта

```
src/
├── domain/                 # Чистая бизнес-логика (без DOM)
│   ├── types.ts            # Типы данных (Lesson, Settings, BellItem, WeekParity) и константы
│   ├── time.ts             # Математика времени, парсинг HH:MM, форматирование секунд
│   ├── parity.ts           # Расчет чётности недели, работа с датами, ISO-форматирование
│   └── collision.ts        # Детекция пересечений и конфликтов пар
├── services/               # Сервисы ввода/вывода
│   ├── storage.ts          # Локальное хранилище (localStorage), санитизация полей, UID
│   ├── ics-export.ts       # Экспорт в iCalendar (RFC 5545) с фолдингом строк на 75 байт UTF-8
│   └── json-transfer.ts    # Экспорт/импорт расписания в JSON и встроенный демо-набор
├── state/                  # Управление реактивным состоянием
│   └── store.ts            # Централизованный реактивный Store (подписчики, фильтры, навигация)
├── components/             # Модули интерфейса (UI)
│   ├── toast.ts            # Всплывающие уведомления и кнопка отмены действия (Undo)
│   ├── modal.ts            # Универсальный контроллер модальных окон и диалог подтверждения
│   ├── live-widget.ts      # Виджет «Текущая пара / таймер до начала / перерыв» (секундный тик)
│   ├── week-strip.ts       # Горизонтальная полоса дней недели с индикаторами-точками
│   ├── schedule-grid.ts    # Сетка расписания (день/неделя), свайпы на мобильных, подсветка ongoing
│   ├── modal-lesson.ts     # Диалог добавления/редактирования пары, пресеты звонков, проверка коллизий
│   ├── modal-settings.ts   # Диалог настроек группы, дат семестра и редактирования звонков
│   ├── print-view.ts       # Генератор разметки для двусторонней печати (@media print)
│   └── actions.ts          # Обработчики экспорта ICS/JSON, импорта, очистки и демо
├── styles/                 # Модульные стили (100% идентичность исходному дизайну)
│   ├── tokens.css          # CSS переменные, цвета, шрифты, радиусы, тени
│   ├── reset.css           # Базовый сброс стилей браузера
│   ├── components.css      # Стили всех карточек, кнопок, форм, модалок и виджетов
│   └── print.css           # Спецификация печатной формы A4 landscape
├── main.ts                 # Точка входа приложения, инициализация слушателей и таймеров
└── index.html              # Разметка шаблона

tests/                      # Юнит-тесты Vitest
├── time.test.ts            # Тестирование функций времени
├── parity.test.ts          # Тестирование календаря и чётности недель
├── collision.test.ts       # Тестирование детектора пересечений
├── ics.test.ts             # Тестирование генератора RFC 5545
└── json-transfer.test.ts   # Тестирование сериализации и импорта данных
```

## 🚀 Команды разработки

- **`npm run dev`** — запуск сервера разработки Vite.
- **`npm run build`** — проверка типов через `tsc` и production-сборка в каталог `dist/`.
- **`npm run preview`** — локальный просмотр production-сборки.
- **`npx vitest run`** — запуск всех 14 модульных тестов.

## ✨ Выполненные требования

1. **Полная декомпозиция:** монолитный файл (~4386 строк) полностью разделён на независимые слои (домен, сервисы, компоненты, стили, стейт).
2. **Типобезопасность:** строгая типизация на TypeScript без `any`.
3. **Тестирование:** ключевая логика (время, даты, чётность, коллизии, экспорт RFC 5545, JSON) покрыта тестами на Vitest (все 14 тестов пройдены успешно).
4. **Визуальная и функциональная идентичность:** сохранены все фичи (сетка звонков, темы Dark/Light, свайпы на телефоне, таймер текущей пары, Undo при удалении, подсветка коллизий в реальном времени, фолдинг кириллицы в ICS на 75 байт, экспорт в печать).
